## 架构概述

HippoRAG 采用神经生物学启发的记忆框架，将知识表示为知识图谱，通过图算法实现多跳检索和推理。

## 核心组件

### 1. HippoRAG 主类

`HippoRAG` 类是系统的主要入口点，协调所有组件的工作。

**主要职责**：
- 初始化和配置管理
- 组件协调
- API 接口提供

**关键属性**：
```python
class HippoRAG:
    global_config: BaseConfig           # 全局配置
    working_dir: str                     # 工作目录
    llm_model: BaseLLM                   # LLM 模型
    embedding_model: BaseEmbeddingModel  # 嵌入模型
    chunk_embedding_store: EmbeddingStore # 文档块嵌入存储
    entity_embedding_store: EmbeddingStore # 实体嵌入存储
    fact_embedding_store: EmbeddingStore # 事实嵌入存储
    graph: GraphInterface                # 知识图谱（DGraphAdapter）
    indexer: Indexer                    # 索引器
    retriever: Retriever                 # 检索器
    qa_engine: QAEngine                  # 问答引擎
```

### 2. Indexer (索引器)

负责将文档转换为知识图谱和嵌入向量。

**主要功能**：
- 文档预处理和分块
- 开放信息提取 (OpenIE)
- 知识图谱构建
- 嵌入向量生成和存储

**核心方法**：
```python
class Indexer:
    def index(self, docs: List[str]) -> None:
        """索引文档"""
        # 1. 预处理文档
        # 2. 提取三元组
        # 3. 构建图
        # 4. 生成嵌入

    def delete(self, docs_to_delete: List[str]) -> None:
        """删除文档"""
```

### 3. Retriever (检索器)

实现多跳检索和图算法。

**主要功能**：
- 事实检索
- 节点链接
- Personalized PageRank (PPR) 重排序
- 多步推理

**核心方法**：
```python
class Retriever:
    def retrieve(self, queries: List[str]) -> List[QuerySolution]:
        """执行检索"""
        # 1. 查询嵌入
        # 2. 事实检索
        # 3. 节点链接
        # 4. PPR 重排序
        # 5. 返回结果
```

### 4. QAEngine (问答引擎)

基于检索结果生成答案。

**主要功能**：
- 上下文聚合
- LLM 推理
- 答案生成

**核心方法**：
```python
class QAEngine:
    def generate_answer(self, query: str, retrieved_docs: List[Document]) -> str:
        """生成答案"""
        # 1. 聚合上下文
        # 2. 调用 LLM
        # 3. 返回答案
```

### 5. GraphManager (图管理器)

管理知识图谱的创建、加载和查询。

**支持的后端**（精简版）：
- `dgraph` (分布式图数据库)

```python
class GraphManager:
    def __init__(self, backend='dgraph'):
        self.backend = backend

    def add_vertex(self, name: str, **attributes):
        """添加顶点"""

    def add_edge(self, source: str, target: str, **attributes):
        """添加边"""

    def load(self, path: str):
        """加载图"""

    def save(self, path: str):
        """保存图"""
```

### 6. EmbeddingStore (嵌入存储)

管理嵌入向量的存储和检索。

**支持的后端**（精简版）：
- PostgreSQL pgvector

```python
class EmbeddingStore:
    def __init__(self, backend='parquet'):
        self.backend = backend

    def add(self, doc_id: str, embedding: np.ndarray, metadata: dict):
        """添加嵌入"""

    def search(self, query_embedding: np.ndarray, k: int) -> List[Document]:
        """相似度搜索"""
```

## 知识图谱构建

### 图结构

HippoRAG 使用异构图，包含多种节点类型：

```
┌─────────────────────────────────────────────────────────┐
│                     知识图谱结构                           │
├─────────────────────────────────────────────────────────┤
│                                                           │
│  节点类型:                                                │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐               │
│  │ 文档节点  │  │ 实体节点  │  │ 事实节点  │               │
│  │ (Passage)│  │ (Entity) │  │  (Fact)  │               │
│  └──────────┘  └──────────┘  └──────────┘               │
│                                                           │
│  边类型:                                                  │
│  ┌─────────────────────────────────────────────────┐   │
│  │ 文档 → 事实        (包含关系)                     │   │
│  │ 事实 → 实体        (主语/宾语关系)                │   │
│  │ 实体 → 实体        (同义/相似关系)                │   │
│  │ 事实 → 文档        (反向索引)                     │   │
│  └─────────────────────────────────────────────────┘   │
│                                                           │
└─────────────────────────────────────────────────────────┘
```

### 图构建步骤

1. **三元组提取**：使用 OpenIE 从文档中提取 (主语, 谓语, 宾语) 三元组
2. **节点创建**：
   - 为每个文档创建文档节点
   - 为每个唯一实体创建实体节点
   - 为每个三元组创建事实节点
3. **边创建**：
   - 文档 → 事实 边
   - 事实 → 实体 边
   - 实体 → 实体 边（基于语义相似度）

## 检索机制

### Personalized PageRank (PPR)

PPR 是 HippoRAG 的核心检索算法，用于在图中找到与查询最相关的文档。

**算法原理**：

```
PR(v) = (1 - α) × Σ(PR(u) / OutDegree(u)) + α × Base(v)

其中:
- PR(v): 节点 v 的 PageRank 值
- α: 阻尼因子 (通常为 0.5)
- Base(v): 节点 v 的基础权重（如与查询的相似度）
- OutDegree(u): 节点 u 的出度
```

**实现特点**：
- 支持个性化基础权重
- 针对异构图优化
- 高效迭代计算

### 多跳检索

```
查询: "苹果公司的联合创始人是谁？"

Step 1: 初始检索
  - 检索相关事实: ("史蒂夫·乔布斯", "联合创始人", "苹果公司")
  - 提取实体: "史蒂夫·乔布斯", "苹果公司"

Step 2: 节点链接
  - 链接实体: "史蒂夫·乔布斯" → "史蒂夫·沃兹尼亚克" (同辈)
  - 链接实体: "苹果公司" → "1976年成立" (时间)

Step 3: 图扩展
  - 扩展图结构
  - PPR 重新排序

Step 4: 最终检索
  - 返回最相关文档
```

### 存储接口

**图存储接口**：

```python
class GraphInterface(ABC):
    @abstractmethod
    def add_vertices(self, n: int, attributes: dict): pass

    @abstractmethod
    def add_edges(self, edges: List[Tuple], attributes: dict): pass

    @abstractmethod
    def save(self, filename: str): pass

    @abstractmethod
    def load(self, filename: str): pass
```

**嵌入存储接口**：

```python
class EmbeddingStore(ABC):
    @abstractmethod
    def add(self, doc_id: str, embedding: np.ndarray, metadata: dict): pass

    @abstractmethod
    def get(self, doc_id: str) -> np.ndarray: pass

    @abstractmethod
    def search(self, query: np.ndarray, k: int) -> List[Document]: pass

    @abstractmethod
    def delete(self, doc_id: str): pass
```
